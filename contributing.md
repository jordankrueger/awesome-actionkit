# Contributing

Thanks for considering a contribution to Awesome ActionKit. This list exists to help the ActionKit community find each other's work.

## What belongs here

- Tools, libraries, and browser extensions that work with ActionKit
- Snippets, templates, and reusable page or mailing components
- SQL recipes and reporting resources
- Data files (blocklists, reference lists) useful for ActionKit deliverability or list hygiene
- Platforms that have documented ActionKit integrations
- Consultants and services focused on ActionKit
- Guides, tutorials, and written references
- Community venues for ActionKit users

## What doesn't belong

- Generic dev tooling with no ActionKit-specific use
- Marketing pages with no product, content, or service behind them
- Resources that require ActionKit staff credentials or non-public URLs
- Your own commercial product without a clear description of what it does

## Entry format

Entries must be single-line and follow this shape:

```
- [Name](URL) - Short, objective description ending with a period. `tag` `tag`
```

- **Name** uses the resource's own branded capitalization.
- **Description** is factual, not promotional. No superlatives.
- **Tags** (optional) go in backticks after the description. Current tags: `paid`, `CH`.
- **Paid products** must include the `paid` tag and live under **Commercial add-ons**.

## Submitting a change

1. Fork the repository.
2. Add your entry in alphabetical order within the appropriate section (except where a section has an intentional ordering, e.g., a curator-first entry).
3. If a section doesn't exist and you think it should, propose it in your PR description before adding entries under it.
4. Run `npx awesome-lint` locally to confirm the list still passes.
5. Open a pull request using the template. Describe who you are and what you're submitting.

## What gets rejected

- Entries that duplicate an existing one without distinct value
- Entries whose primary purpose is SEO or referral
- Entries pointing to dead or authwalled pages
- Entries that promote a product while describing it (save the pitch for your own site)
